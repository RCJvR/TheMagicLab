Graph plotter.

Set up your Cartesian plane — range, increments and gridlines — then plot linear, parabolic, hyperbolic, exponential, trig and other graphs onto it. Intercepts, turning points and asymptotes are marked for you.

Cartesian plane

Graphs

Points

Mark any point with a name, e.g. A(2 ; 3). Useful for the given points in a question.

Tips

  • Every value box accepts an expression: 1/2, -3, sqrt(2), pi. A comma works as a decimal sign (2,5).
  • Choose Custom to type any y = …, e.g. 2x^2 - 3x + 1, 3/(x-1) + 2, 2^x, sin(2x), |x - 2|, sqrt(x), ln(x), log(x).
  • Restrict a graph’s domain under More options; open endpoints are drawn as hollow dots.
  • Turn on Degrees (trig) so sin, cos and tan work in degrees, and set the x increment to 30°, 45° or 90°.
  • Hover over the plane to read off values. Copy link saves the whole graph in a link you can share with your class.
  • To put the graph in a test or worksheet: Copy image and paste it into Word or Google Docs, or choose Print / add to document for a set size in cm, a caption and several copies per page.
