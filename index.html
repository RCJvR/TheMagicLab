1 What is Java?

Java is one of the most popular programming languages in the world. It is used to build apps, games, websites, and much more. Many schools and universities teach Java as a first programming language.

2 Variables and Storing Information

A variable stores information that your program can use later. In drawing programs, variables are useful for storing things like the number of sides in a shape, step counts, colours, or positions.

int side = 4;

Breaking that down:

  • int — the type. It means this variable holds a whole number (integer).
  • side — the variable name. It stores the number of sides in a shape.
  • = 4 — the value stored in the variable.
  • ; — every Java statement ends with a semicolon.
Variable names must start with a letter and cannot contain spaces. Java is case-sensitive — side and Side are different variables.

4 Calling a Method

A method is an action that an object can perform. You call a method using a dot between the object name and the method name.

Breaking that down:

  • n — the name of your pen object.
  • . — the dot connects the object to its method.
  • move() — the method name. This tells the pen to move forward 1 unit.
  • turnRight(90) — passes the number 90 as an argument (extra information the method needs).
The dot notation object.method() is one of the most important patterns in Java. You will see it everywhere.

6 Repeating with a For Loop

A for loop repeats a block of code a set number of times. On the last slide we wrote n.move(); 5 times by hand. Imagine doing that 20 times for a full side! A loop makes it much shorter:

The three parts inside the brackets are:

  • int i = 0 — create a counter variable and start it at 0.
  • i < 20 — keep looping while i is less than 20.
  • i++ — after each loop, add 1 to i. (i++ means i = i + 1).
The loop runs 20 times (when i = 0, 1, 2 ... 19). When i reaches 20, the condition i < 20 is false and the loop stops.
