Command cheat sheet

  • Pen n = new Pen();
    creates a pen object
  • n.move(100);
    draws forward 100 pixels
  • n.turnRight(90);
    turns clockwise 90°
  • n.turnLeft(45);
    turns anti-clockwise 45°
  • n.setColor(255, 100, 50);
    RGB colour (0–255)
  • n.setSpeed(8);
    changes drawing speed (1–10)
  • n.penUp();
    moves without drawing
  • n.penDown();
    starts drawing again
  • n.setPosition(200, 120);
    jumps to a place
  • n.setDirection(90);
    points down
  • for(int i = 0; i < 4; i = i + 1) { ... }
    repeats commands
