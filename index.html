Command reference

Pen n = new Pen(); create a pen object
n.move(); move forward 1 unit
n.turnRight(90); turn clockwise 90°
n.turnLeft(45); turn anti-clockwise 45°
n.setColor(255,100,50); RGB colour 0–255
n.setSpeed(8); speed 1–10
n.penUp(); move without drawing
n.penDown(); start drawing again
n.setPosition(200,120);jump to coordinates
n.setDirection(90); point in a direction
for(int i=0; i<4; i++)repeat 4 times
