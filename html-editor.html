1 Basic HTML Tags

HTML gives a webpage its structure. The browser reads tags from top to bottom and uses them to decide what each piece of content means.

Doctype

<!DOCTYPE html> tells the browser to use modern HTML rules.

Head and body

<head> stores page information. <body> stores visible content.

Headings

<h1> is the main heading. <h2> to <h6> create smaller headings.

Comments and text

Comments explain code. <b>, <i>, and <u> change simple text style.

TagThe instruction, such as img or h1.
AttributeThe setting name, such as src or type.
ValueThe setting content, such as photo.jpg.
<img src="photo.jpg" alt="A school project">

2 Making a List

Lists group related items. Use <ul> for bullets and <ol> for numbered steps. Each item goes inside an <li> tag.

<ul> <li>Plan the page</li> <li>Write the HTML</li> </ul> <ol type="A"> <li>Save the file</li> <li>Open it in a browser</li> </ol>
The type attribute changes the marker style. Ordered lists can use 1, A, a, I, or i. Unordered lists can use disc, circle, or square.

Quick check: which tag creates each list item?

3 Images and File Paths

The image tag uses attributes. src tells the browser where the image file is. alt gives a text description if the image cannot load or if a screen reader is used.

Same folder

src="robot.png" works when the image and HTML file are saved together.

Different folder

src="images/robot.png" looks inside a folder called images.

<img src="images/robot.png" alt="A small robot drawing" width="320">
Using only width lets the browser keep the image aspect ratio. Setting both width and height can stretch the picture if the numbers do not match the original shape.

Quick check: what does alt text describe?

4 Tables

Tables organise information into rows and columns. Start with <table>, create rows with <tr>, add headings with <th>, and add normal cells with <td>.

<table> <tr> <th>Name</th> <th colspan="2">Marks</th> </tr> <tr> <td rowspan="2">Ava</td> <td>HTML</td> <td>85</td> </tr> </table>

colspan

Makes one cell stretch across more than one column.

rowspan

Makes one cell stretch down through more than one row.

Basic table formatting often starts with border-collapse, border, padding, and background colours for header cells.

5 RGB and Hex Colours

Web design colours are often written as RGB or hex. RGB uses three numbers for red, green, and blue. Hex uses six characters after a #, with two characters for each colour channel.

color: rgb(6, 182, 212); background-color: #06b6d4;

RGB

rgb(255, 0, 0) is red because the red channel is full.

Hex

#ff0000 is the same red written in hexadecimal.

Good web design uses colour for meaning and contrast, not only decoration. Text should stay easy to read.

Quick check: which value is a hex colour?

6 What CSS Does

HTML describes the structure and meaning of content. CSS controls how that content looks: colours, spacing, borders, fonts, layout, and more.

Inline CSS

Written directly on one tag with style="...".

Internal CSS

Written inside a <style> tag in the page head.

External CSS

Written in a separate .css file and linked to the HTML page.

Preferred method

External CSS keeps structure and styling separate, cleaner, and easier to reuse.

p { color: #334155; }
Declarationcolor: #334155;
Propertycolor, the thing being changed.
Value#334155, the setting being applied.

The colon separates property and value. The semicolon ends the declaration.
