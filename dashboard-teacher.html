Paper Assembler

Build a write-on question paper in sections: cover page, per-question analysis, numbered questions, answer lines and a memo. Everything stays in this browser.

In the header and footer, type {page} for the page number and {pages} for the total, e.g. Page {page} of {pages}. The cover page has no header or footer. Leave a box empty to use its default.
With answer lines on, a written question gets its marks plus 2 lines (1 mark = 3 lines, 2 marks = 4 lines) unless you set a number on the question.

Assessment Tracker

Plan the year's assessment tasks by term, weight them, enter marks and watch each learner's year mark build up.

Weightings are percentages of the final year mark and should add up to 100. Check your school's or the IEB's own weightings for each subject.
The year mark so far counts only the tasks that have a mark, so it is comparable with the final result as the year goes on. The percentage in brackets shows how much of the year's weighting that covers.
The tracker saves itself in this browser. The file includes your class lists, tasks and marks.

Timetable Planner

Set up your periods, teachers, classes, subjects and lessons, then let the planner build a clash-free timetable. Adjust it by hand, print it for every class and teacher, and save it to a file.
